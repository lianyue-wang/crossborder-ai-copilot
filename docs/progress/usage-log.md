# 使用日志

> 记我自己用这个工具时的真实情况。用途有两层：
> ① 找出"哪里不好用"（这是改进的唯一依据，比任何评测都真实）
> ② 三个月后回看，能证明它真的在被用

## 规则

- **每周至少 1 条**，用了就记，不用也记（写"这周没用，因为 XX"）
- 只记事实：哪天、哪个 ASIN/关键词、我干了什么、AI 哪里不对、我怎么改的
- **不记"效果很好"这种话**。没有具体问题的记录没有价值
