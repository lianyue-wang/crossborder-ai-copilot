## 三、分组对比分析

### 3.1 成都 vs 一线城市技能差异

| 技能 | 成都(35个) | 一线城市(65个) | 差异 | 原因 |
|------|-----------|---------------|------|------|
| Python | 80% | 89% | -9% | 成都小公司更多用低代码 |
| LangChain | 49% | 63% | -14% | 一线技术深度要求更高 |
| RAG | 66% | 75% | -9% | 一线RAG需求更标准化 |
| Dify | 46% | 40% | +6% | 成都小公司更依赖低代码 |
| AI编程工具 | 43% | 35% | +8% | 成都创业公司更看重效率 |
| Java | 31% | 22% | +9% | 成都传统IT公司更多 |
| 全栈开发 | 40% | 32% | +8% | 成都小公司一人多能更突出 |
| Docker | 14% | 23% | -9% | 成都运维要求更低 |
| 向量数据库 | 40% | 52% | -12% | 成都更多用低代码封装 |

**结论**：成都岗位技术要求略低于一线，但AI编程工具和低代码平台使用率更高，更务实。

### 3.2 本科岗 vs 大专岗技能差异

| 技能 | 本科岗(62个) | 大专岗(38个) | 差异 | 原因 |
|------|-------------|-------------|------|------|
| Python | 95% | 71% | **-24%** | 大专岗更多用低代码平台 |
| LangChain | 71% | 37% | **-34%** | 大专岗更多用Dify/Coze |
| RAG | 85% | 50% | **-35%** | 大专岗RAG要求更低 |
| Prompt Engineering | 71% | 32% | **-39%** | 大专岗不强调理论 |
| Dify | 34% | 55% | **+21%** | 大专岗更偏好低代码 |
| Coze | 19% | 42% | **+23%** | 大专岗/创业公司更常用Coze |
| 向量数据库 | 60% | 26% | **-34%** | 大专岗用低代码封装了 |
| FastAPI | 42% | 13% | **-29%** | 大专岗后端要求降低 |
| Docker | 29% | 5% | **-24%** | 大专岗不要求运维 |
| PyTorch/微调 | 24% | 0% | **-24%** | 大专岗完全不碰训练 |

4. Java在大专岗中占比37%，比本科岗18%高出一倍

| 公司特征 | 为什么不查学历 | 典型岗位数量 |

- JD只写"本科"未写"统招"，简历上写"本科"即可

**高风险本科岗（不建议投，约6个）：**
- 明确写"统招本科"
- 200人以上有完善HR体系
- 有背调流程的公司

**最安全的公司类型（按安全度排序）：**

## 五、中小公司AI应用岗能力画像总结

### 5.1 核心画像

> 一个会用AI工具快速产出代码、懂点业务逻辑、能独立跑通完整项目的"全栈型选手"——不要求算法深度，要求落地速度。

### 5.2 真实要求拆解

| 维度 | 大厂/中厂要求 | 中小公司真实要求 |
|------|-------------|---------------|
| 编程能力 | 精通Python，手写代码能力强 | **会用Cursor/Copilot快速产出**，能看懂代码就行，Java背景也可 |
| 技术深度 | LangChain/RAG/向量数据库全套精通 | 用过Dify/Coze搭过demo就行，LangChain了解即可 |
| 项目经验 | 非玩具级完整项目，有线上流量 | 做过1个能演示的项目，能讲清楚逻辑 |
| 学历 | 本科起步，硕士有竞争力 | **大专即可，68%的本科岗在中小公司中不查学信网** |
| 经验 | 3-5年，有大厂背景加分 | 1-3年甚至不限，**接受转行** |
| 团队协作 | 分工明确，专人专岗 | **一人多能，全栈都要会一点** |
| 运维部署 | Docker/K8s/CI/CD全套 | 能部署到服务器就行 |
| 模型训练 | LoRA/QLoRA微调 | **完全不需要**，用API就行 |
