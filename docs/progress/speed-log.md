## 怎么用

1. **比值 > 1.5 连续两次** → 估算方法有问题，下次按 `实际 × 1.3` 报。不是能力问题，是估算问题。
2. **同一类事卡两次**（比如两次都卡在数据清洗） → 是系统性瓶颈，要么补这块基础，要么改方案绕开。
3. **比值 < 0.8** → 可能是估高了，也可能是跳了验收。回头核对验收清单，别自己骗自己。

面试官问"你怎么保证交付节奏"，能拿出这份日志比说"我很自律"强。它证明的是：**能估算、能复盘、能修正估算。**
