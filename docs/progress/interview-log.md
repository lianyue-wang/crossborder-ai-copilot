# 面试日志

> 每场面试后 **24 小时内**记一条。不记就等于白面。这是校准简历和准备重点的唯一依据。

## 规则

1. 只记事实，不记情绪
2. 重点记「我哪句答崩了」，不记「面试官人很好」
3. 同一个问题被问第二次，说明简历写法有问题，要改简历不是改答法

## 记录模板

```
### YYYY-MM-DD  <公司>  <岗位>  <结果：未过 / 待定 / 过>

**问到的题（按顺序）**
1.
2.

**答崩的点**（原话 + 我当时怎么答的 + 应该怎么答）
-

**简历哪一行被追问最多**
-

**我准备的哪块没用上**
-

**下次改什么（具体动作，不写"加强学习"）**
-
```
